# Projet TP de Algebre Tensorielle dans le traitement d'image

 - Contraction Tensorielle
 - Filtrage par convolution en 2D

## Installation
1. Cloner le dépôt : `git clone https://github.com/Edouard-prog/projetAlgebreTensorielle.git`
2. Ouvrir le projet dans un notebook avec prosseur CPU 
3. Lancer : `mode normal
